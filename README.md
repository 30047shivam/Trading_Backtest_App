# **Trading Backtest Application**

A Flask-based web application for backtesting trading strategies. The application reads trade data from a CSV file and displays it in a user-friendly, web-based table.

---

## **Features**
- Reads trade data from a CSV file.
- Automatically generates sample trade data if the file is missing.
- Displays trade data in a responsive and styled web interface.
- Easy to extend and integrate with other trading or financial tools.
